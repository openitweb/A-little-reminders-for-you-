# Hi Baby 💗 — GitHub Pages Website

## Files
- `index.html` — complete clickable website
- `music.mp3` — background music
- `images/` — all 8 page images

## How to publish on GitHub
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select your main branch (usually `main`) and `/ (root)`.
7. Save and wait for GitHub Pages to publish.

The music is set to loop and begins after the visitor taps the page, because phone browsers commonly block audio autoplay until a user interaction.
